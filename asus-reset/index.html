步驟勾選

確認 Windows 版本

先確認這台電腦是 Windows 10 還是 Windows 7。

全程接上電源。 重設時可能會黑屏、重新開機數次，不要強制關機。
A1

開啟系統資訊

如果看得到桌面，點左下角的開始按鈕，依照其中一條路徑操作。

開始Start › 設定Settings › 系統System › 關於About

若開始選單沒有「設定」，改走下列 Windows 7 路徑。

開始Start › 控制台Control Panel › 系統及安全性System and Security › 系統System
A2

看 Windows 版本

找到 Windows edition（Windows 版本）或 Windows specifications（Windows 規格）。

Windows 10下一步：檢查磁碟加密 Windows 7下一步：檢查磁碟加密

下一步：檢查磁碟加密 ›

檢查磁碟加密

查看加密狀態，不需要變更設定。

B1

在控制台找到 BitLocker

開始Start › 控制台Control Panel › 系統及安全性System and Security › BitLocker 磁碟機加密BitLocker Drive Encryption

Windows 10 也可點開始，搜尋「BitLocker」或「管理 BitLocker」（Manage BitLocker），再點搜尋結果。

B2

判斷是否已開啟

畫面英文 中文與判斷
BitLocker on / Turn off BitLocker 已開啟／關閉 BitLocker：目前已加密
BitLocker off / Turn on BitLocker 已關閉／開啟 BitLocker：目前未啟用
Suspended / Protection suspended 已暫停保護：可能仍有加密

查看 C:，以及其他內部磁碟。不要點 Turn on 或 Turn off。

若 Windows 7 Home 找不到此選項，可能是不支援標準 BitLocker 的版本；若是 Windows 10，還要做下一步檢查裝置加密。
B3

Windows 10：額外檢查裝置加密

開始Start › 設定Settings › 更新與安全性Update & Security › 裝置加密Device encryption

顯示 On（開啟）或 Device encryption is on 代表已開啟；Off（關閉）代表未開啟。找不到此頁面時，可能是硬體或版本不支援。不要為了重設而啟用或停用加密。

B4

若要求輸入復原金鑰才處理

不需要關閉 BitLocker。若重設時沒有要求復原金鑰，直接繼續。

若出現 BitLocker recovery（BitLocker 復原）藍色畫面，請原擁有者用另一台裝置開啟 個人 Microsoft 帳號復原金鑰頁面，比對 Recovery key ID（復原金鑰識別碼），使用相符的 48 位數金鑰。Windows 7 的金鑰也可能存於當初列印或儲存的位置。

找不到金鑰且畫面無法繼續：停止操作並聯繫原電腦擁有者。可能需要由熟悉電腦的人使用 USB 重新安裝；不要嘗試猜金鑰或更動 BIOS。

Windows 10 · 方法一

從設定重設電腦

可以正常登入 Windows 10 時，使用此方法。

接上電源。 重設時請勿強制關機。

10-1

進入復原設定

開始Start › 設定Settings › 更新與安全性Update & Security › 復原Recovery
✓
開始使用Get started

在 Reset this PC（重設此電腦）區塊內點選。

也可在開始選單搜尋「重設此電腦」或「Reset this PC」，點選搜尋結果。

10-2

移除所有項目

✓
移除所有項目Remove everything

移除原使用者帳號、個人檔案、應用程式和設定。

✕ 不要選：保留我的檔案 Keep my files
10-3

選擇重新安裝方式

✓
雲端下載Cloud download

若有穩定網路，從 Microsoft 下載安裝檔。

如果找不到此選項、網路無法使用，或雲端下載失敗，可以選 Local reinstall（本機重新安裝）。舊版本可能直接進入下一步。

10-4

打開變更設定

✓
變更設定Change settings

進入 Additional settings（其他設定）後點此連結，不要直接按下一步。

10-5

設定清除所有資料

英文選項 中文 設定
Clean data? 清理資料？ Yes／是
Delete files from all drives? 刪除所有磁碟機的檔案？ Yes, all drives／是，所有磁碟機
Download Windows? 下載 Windows？ Yes／是（雲端下載時）
Restore preinstalled apps? 還原預先安裝的應用程式？ No／否（若出現）

若只有一個可清除的磁碟，可能不會顯示 all drives 選項。設定完成後點 Confirm（確認），再點 Next（下一步）。

10-6

較舊 Windows 10：如果沒有變更設定

只有在看到下列畫面時才需操作；若已完成上一個步驟，直接跳到下一步。

✓
所有磁碟機All drives

若詢問要清除哪些磁碟，不要選僅安裝 Windows 的磁碟。

✓
完整清理磁碟機Fully clean the drive / Remove files and clean the drive
✕ 不要選：只移除我的檔案 Just remove my files
10-7

確認後開始重設

在 Ready to reset this PC（準備重設此電腦）畫面核對將移除帳號、檔案和應用程式。若有額外磁碟，確認已選擇全部磁碟；若不確定，返回上一頁。

✓
重設Reset
接下來不要手動關機。等電腦自行重開機並進入 Windows 初始設定。

Windows 10 · 方法二

從修復環境重設電腦

無法正常登入 Windows 10 時，使用此方法。

R1

從登入畫面進入修復環境

若能看到 Windows 登入畫面，點右下角 Power（電源）。按住鍵盤 Shift 鍵，同時點 Restart（重新啟動）；出現藍色 Choose an option 畫面再放開。

若電腦已進入 Automatic Repair（自動修復），點 Advanced options（進階選項）。若兩者皆無法出現，請停止並聯繫原擁有者，不要反覆強制關機。

畫面因版本而異，請參考：　ASUS 官方圖文教學

R2

點選疑難排解與重設

✓
疑難排解Troubleshoot
✓
重設此電腦Reset this PC
R3

移除全部資料與完整清理

✓
移除所有項目Remove everything
✓
所有磁碟機All drives

若有出現磁碟範圍選項。

✓
完整清理磁碟機Fully clean the drive

若出現復原金鑰要求，回到 BitLocker 檢查章節。

R4

選擇安裝方式並重設

✓
雲端下載Cloud download

有網路時優先選擇；否則可選 Local reinstall（本機重新安裝）。

按 Reset（重設）開始，完成後選擇「完成重設及關機」。不同版本的選項順序可能不同，但清除範圍與完整清理設定應保持一致。

Windows 7 · 方法一

ASUS 原廠還原

適用保有原廠復原分割區的舊款 ASUS 筆電。

重要：Windows 7 原廠還原並不等於安全抹除。它通常只還原選取的硬碟，其他實體硬碟可能仍有資料；若需要確保舊資料難以復原，請由熟悉電腦的人進行磁碟安全清除與重新安裝。
7-1

關機後按 F9

在 Windows 7 開始選單點 Shut down（關機）。電腦完全關機後，按電源鍵開機，立即連續按鍵盤上方的 F9，直到出現還原畫面。

若直接進入原本的 Windows，請改走 控制台備用方式，不要修改 BIOS。

7-2

選擇 Windows Setup

✓
Windows 安裝程式（已啟用 EMS）Windows Setup [EMS Enabled]

若出現 Windows Boot Manager（Windows 開機管理程式），選取此列並按 Enter。若直接進入 ASUS 還原精靈，跳到下一步。

7-3

選擇語言並進入 ASUS 精靈

選擇語言Select Language › 下一步Next › ASUS 預載精靈ASUS Preload Wizard › 下一步Next

選擇熟悉的語言；閱讀原廠提示，點下一步。若實際畫面不是 ASUS Preload Wizard，不要隨意選擇，先詢問原擁有者。

語言選擇畫面因型號而異，請參考：　ASUS X53U 使用手冊（英文）

7-4

選擇整個硬碟

✓
將 Windows 還原至整個硬碟Recover Windows to entire HD

優先選第二項，清除該硬碟原有分割區並建立新的 C 槽。

第三項 Recover Windows to entire HD with two partitions（將 Windows 還原至整個硬碟並建立兩個分割區）也會重建該硬碟的 C、D 槽。

✕ 不要選：只還原第一個分割區 Recover Windows to first partition only

確定選的是整顆硬碟後，點 Next（下一步）。若只有 Default Partition（預設分割區）等選項，先停止，不能假設 D 槽也會清除。

7-5

開始原廠還原

依畫面點 Next（下一步）、Recover（復原）或 Yes（是），若有顯示 Finish（完成）或 Reboot（重新開機），依原廠提示操作。還原過程可能多次重新啟動。

不要在還原過程強制關機；如果報錯或沒有提供整顆硬碟選項，先停止並聯絡原擁有者。

確認及進度畫面因型號而異，請參考：　ASUS 原廠手冊轉載

Windows 7 · 方法二

從控制台還原電腦

開機按 F9 無效時，使用此方法。

C1

進入控制台

開始Start › 控制台Control Panel › 系統及安全性System and Security
C2

開啟備份與還原

✓
備份與還原Backup and Restore
C3

進入復原設定

✓
復原系統設定或您的電腦Recover system settings or your computer
C4

選擇進階復原方法

✓
進階復原方法Advanced recovery methods
✕ 不要選：開啟系統還原 Open System Restore
C5

選擇恢復原廠狀態

✓
將電腦恢復至出廠狀態Return your computer to factory condition
如果沒有這個選項，只有 Reinstall Windows (requires Windows installation disc)（重新安裝 Windows，需要安裝光碟），請停止。若使用一般重新安裝，有可能留下 Windows.old 或其他磁碟資料。
C6

略過備份並重新開機

✓
略過Skip

若系統詢問是否備份，選 Skip。

✓
重新啟動Restart

若進入原廠還原精靈，回到 Windows 7 原廠還原的整個硬碟選項。若不提供清除全部磁碟選項，停止並詢問原擁有者。

回到 ASUS 原廠還原 › 已完成還原 ›

完成重設及關機

看到 Windows 初始設定畫面後即可關機。

F1

辨認初始設定畫面

Windows 10 通常會要求選擇國家／地區或鍵盤；Windows 7 可能要求建立使用者名稱。到這裡代表已進入新的設定流程。

不要登入帳號，也不需要建立新帳號。 如果直接進入舊桌面或仍有舊帳號，請通知原擁有者。

F2

安全關機

若畫面有 Power（電源）圖示，點選後選 Shut down（關機）。若沒有電源選單，確認已停在初始設定畫面且沒有正在安裝或更新，再短按一次實體電源鍵，等待正常關機。

若短按無反應或只進入睡眠，不要長按強制關機；停留在初始設定畫面。

部分版本沒有電源圖示。　ASUS 官方重設說明
